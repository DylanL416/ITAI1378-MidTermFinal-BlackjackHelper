# AI Usage Log

## CardVision AI Assistance Log

This document summarizes how AI tools were used during the development of CardVision.

The AI system was used as a support and brainstorming tool. Final decisions, project direction, debugging, and implementation choices were reviewed and managed by myself.

---

## Entry 1 — Project Brainstorming

AI assistance was used to brainstorm possible computer vision project ideas related to blackjack strategy and wearable interfaces.

Topics discussed:
- project scope ideas
- feasibility for a Tier 2 project
- possible datasets
- high-level computer vision workflow

---

## Entry 2 — Repository and README Structure

AI assistance helped organize the GitHub repository structure and improve the project README formatting.

Topics discussed:
- repository folder layout
- README organization
- project milestone planning
- formatting technical sections
- Pushing to github

---

## Entry 3 — Notebook Pipeline Organization

AI assistance was used to help structure the Google Colab notebook pipeline into a cleaner top-to-bottom workflow.

Topics discussed:
- separating dataset generation and training sections
- organizing helper functions
- improving notebook readability
- reducing duplicated code

---

## Entry 4 — YOLOv8 Integration Guidance

AI assistance was used to discuss how YOLOv8 could connect to the blackjack recommendation engine.

Topics discussed:
- synthetic dataset generation
- object detection pipeline design
- dealer/player zone grouping
- rank-only class design

---

## Entry 5 — Debugging and Error Review

AI assistance was used to help review notebook errors and identify missing imports or incorrect execution order.

Topics discussed:
- missing helper functions
- runtime dependency issues
- notebook execution order
- import and variable errors

---

## Entry 6 — Documentation Review

AI assistance helped review documentation wording and improve consistency between the README, notebook, and project scope.

Topics discussed:
- aligning README with the final rank-only design
- simplifying technical explanations
