# Assets

This folder stores visual assets used in the CardVision project.

Possible assets include:

- blackjack table example images
- YOLO detection screenshots
- presentation graphics
- logo concepts
- synthetic training image previews

CardVision V1 primarily generates synthetic blackjack board images directly inside the notebook for YOLOv8 training.

These synthetic images simulate:

- dealer card placement
- player card placement
- blackjack table layout
- rank-only object detection labels

Future versions may include real photographed playing cards and webcam screenshots.
